# Projeto Cadastro de Livro - Encapsulamento em Java

## Atividade da Matéria de Programação de APP
## DS-Senai/BA
Este projeto demonstra a aplicação prática do conceito de **Encapsulamento** e **Validação de Atributos** em Java através de uma classe de cadastro de livros.

## Tecnologias Utilizadas
- **Linguagem:** Java
- **IDE:** IntelliJ IDEA
- **Controlo de Versão:** Git & GitHub

## Conceitos de POO Aplicados
- **Encapsulamento (`private`):** Atributos protegidos contra acessos diretos não autorizados (`titulo`, `autor`, `numeroPaginas`).
- **Métodos Getters e Setters:** Controle de acesso de leitura e escrita para garantir a integridade dos dados.
- **Validação de Dados:** Validação do número de páginas no método `setNumeroPaginas()`, evitando valores zerados ou negativos.

## Como Executar
1. Clona este repositório: https://github.com/matheusvm10/Java-poo-cadastro-livro.git
2. Abre o projeto no IntelliJ IDEA.
3. Executa a classe `Main.java`.
